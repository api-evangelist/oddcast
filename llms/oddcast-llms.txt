# Oddcast

> Oddcast is a New York-based creative media technology company building speaking-character, avatar, and text-to-speech products. For developers it operates two API-driven products: Vocalware (cloud text-to-speech via HTTP/REST and JavaScript/HTML5 APIs, hundreds of voices in 30+ languages) and SitePal (an AI avatar platform embedded and controlled through a JavaScript VHost API).

## APIs

- [Vocalware Text-to-Speech API](https://www.vocalware.com): pay-as-you-go cloud TTS; HTTP/REST for mobile/standalone/server apps and JavaScript/HTML5 for browsers.
- [SitePal Avatar API](https://www.sitepal.com): embeddable AI avatars controlled at runtime via a JavaScript (VHost) API (sayText, sayAudio, sayAI, stopSpeech, setStatus, setFacialExpression, setBackground).
